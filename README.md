# Impossible Tik Tak Toe
Impossible Tik-Tak-Toe is a project that implements an unbeatable bot for the game of Tic-Tac-Toe. The primary goal of this project was to enhance my programming skills while applying my knowledge of game theory and AI development.
 
It consists of two main components: a program that constructs a decision tree using the Minimax algorithm, mapping all possible moves of the bot, and a web platform that provides a visual interface to users to play against it.

## Requirements
* Node.js
* Python3

## Installation
To install and run the Impossible Tik-Tak-Toe game, follow these steps: 

1. Clone the repository: 
``` bash
git clone https://github.com/LuizF14/impossible-tik-tak-toe.git
```

2. Navigate to the client directory:
```bash
cd impossible-tik-tak-toe/client
```

3. Install the required dependencies:
``` bash
npm install
```

## Usage
To generate the bot decision tree, navigate to the project's main directory and run the following python code:
``` bash
python3 main.py
```
To start the game visual interface, navigate to `/client` directory and run the command: 
``` bash
npm start
```
You can access the game in your web browser at `localhost:3000`.
